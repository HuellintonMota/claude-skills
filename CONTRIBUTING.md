# Como contribuir

## Pedir melhoria ou relatar problema

Abra uma issue: https://github.com/HuellintonMota/claude-skills/issues/new/choose

- **Melhoria em uma skill**: o que você quer, por quê e um exemplo.
- **Problema**: a skill, a versão (`bash ~/.claude/claude-skills/setup --versao`), o agente, o
  sistema e como reproduzir.

## Pull requests

- Abra o PR só depois de combinar a mudança na issue, e cite a issue no PR ("Relacionado a #").
- A `main` é protegida: o PR só entra com a aprovação do mantenedor.

## Segredos

O repositório é público. Não coloque senha, token, URL de webhook, IDs pessoais ou dados de clientes
em issue, PR ou commit.
